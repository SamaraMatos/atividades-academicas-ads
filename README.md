# Atividades Acadêmicas - Python

Repositório destinado ao armazenamento de atividades práticas desenvolvidas durante minha graduação em Análise e Desenvolvimento de Sistemas.

## Tecnologias e conceitos

- Python
- Programação Orientada a Objetos
- Estruturas de dados
- Funções
- SQLite
- SQL
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Manipulação e análise de dados

## Atividades

### Análise de vendas
Análise de dados de vendas utilizando Python, SQLite, Pandas, Matplotlib e Seaborn.

### Sistema de pacientes
Sistema de cadastro e consulta de pacientes utilizando Programação Orientada a Objetos e geração de estatísticas.

### Sistema de biblioteca
Sistema para cadastro, listagem e busca de livros, com geração de gráfico por gênero.

### CRUD de contatos
Exercício de integração entre Python e SQLite, trabalhando com operações de inserção, consulta, atualização e exclusão de dados.

### Análise de dados com Pandas
Manipulação, limpeza, filtragem e análise de dados utilizando Pandas.

## Objetivo

Praticar e consolidar conhecimentos de programação em Python, banco de dados, análise de dados e programação orientada a objetos por meio de atividades práticas.
